# EXPERIMENT SPECIFICATION — Compute-Aware Proxy-Calibrated Topology NAS + Stability-Aware CfC Regularization (Two-Timescale as Stretch)

0. PURPOSE AND SCOPE

---

Goal: Maximize scientific output per compute by:
(A) Designing a compute-aware topology search that remains proxy-guided (train-free per candidate) but is empirically calibrated using a small, fixed training budget.
(B) Designing stability-aware CfC regularization supported primarily by toy dynamical experiments that do not require EEG data.
(C) Validating (A) and (B) with minimal EEG confirmation experiments.

Major Changes:

1. Compute-Aware Proxy-Calibrated Topology NAS (NEW mechanism: calibration + compute-aware constrained search; uses existing proxy metrics).
2. Stability-Aware CfC Regularization (NEW mechanism: sensitivity/Jacobian regularizer + Δt-randomization consistency; optional stability filter for graphs).

Stretch Goal:
3) Two-timescale recurrence (NEW architecture option) — only executed if compute/time permit.

This document specifies:

* Models, constraints, proxies, objectives, metrics, and evaluation protocol.
* Toy tasks (mechanism validation) and minimal EEG confirmation tasks.
* What is “new mechanism” vs “parameter change / existing functionality”.

1. NOTATION

---

Indices:

* t ∈ {0,1,...,T-1}: discrete time step index.
* i,j: node indices in a recurrent layer (hidden units / neurons).
* s: random seed index.
* g: graph index (candidate wiring).

Signals:

* x_t ∈ R^{D}: input at time step t.
* h_t ∈ R^{H}: hidden state at time step t.
* y_t: model output at time step t (task dependent).
* Δt_t > 0: time increment (can be constant or randomized).

Model:

* Update map (CfC cell): h_{t+1} = U_θ(h_t, x_t, Δt_t).
* Readout: ŷ = R_ψ({h_t}_{t=1..T}) (may use last state h_T or pooled states).

Perturbations:

* ε: perturbation on hidden state or input.
* η_t: input noise.

Graph:

* G = (V,E) with |V| = H nodes; E is directed edge set.
* Adjacency matrix A ∈ {0,1}^{H×H}, where A_{ij}=1 if edge j→i exists (j influences i).

Masked recurrent weights:

* W ∈ R^{H×H}: base recurrent weight matrix.
* Effective weights: W_eff = W ⊙ A (elementwise mask).
  All graph constraints are enforced on A (structure), not on W values.

Expectation:

* E[...] denotes expectation over specified random draws (seeds, time steps, noise, Δt, etc.).

2. BASELINES AND SYSTEM VARIANTS

---

2.1 Baseline CfC + baseline wiring (EXISTING)

* Use existing CfC implementation used in Paper 2/3.
* Wiring choices:
  (i) fully connected baseline: A_{ij}=1 for all i,j (or dense block as currently used), OR
  (ii) existing NCP wiring generator (from ncps) without additional constraints, OR
  (iii) previously used WS-Flex / proxy-guided wiring (current baseline in Paper 3).

2.2 Variant: Compute-Aware Proxy-Calibrated Topology NAS (MAJOR CHANGE 1; NEW mechanism)

* Search is performed over adjacency A subject to hard constraints (Section 3).
* Candidate evaluation during search uses ONLY proxies and compute estimates, not model training.
* A small calibration set uses low-fidelity training to learn a mapping from proxies→predicted performance/robustness (Section 4).

2.3 Variant: Stability-Aware CfC Regularization (MAJOR CHANGE 2; NEW mechanism)
Add regularization terms to the training objective that bias hidden dynamics toward reduced sensitivity.
Includes:
(A) Sensitivity/Jacobian regularization (NEW).
(B) Δt randomization and optional Δt consistency regularization (NEW).
(C) Optional graph feasibility micro-test filter (NEW; no training) used only to reject obviously unstable candidate wirings.

2.4 Stretch Variant: Two-Timescale Recurrence (STRETCH; NEW architecture)

* Maintain fast and slow states:
  h^f_{t+1} = U^f(h^f_t, h^s_t, x_t, Δt_t)
  h^s_{t+1} = U^s(h^s_t, Pool({x_{t-k..t}}), Δt^s_t) updated every M steps
* Not required for primary contributions; only run if compute permits.

IMPORTANT: This spec does not assume any changes to the core CfC closed-form equations beyond masking (wiring) and adding regularization / Δt handling.

3. COMPUTE-AWARE TOPOLOGY SEARCH SPACE SPECIFICATION (MAJOR CHANGE 1)

---

3.1 Search object
Each candidate topology is an adjacency A ∈ {0,1}^{H×H} defining a wired recurrent layer.

3.2 Hard structural constraints (NEW to search space)
These constraints must hold for every A considered in search.

C1) Edge budget (compute control)

* Total edges: |E| = sum_{i,j} A_{ij}
* Constraint: |E| ≤ E_max

C2) Degree constraints (avoid dead ends / degenerate graphs)
Define:

* in-degree of node i: deg_in(i) = sum_j A_{ij}
* out-degree of node j: deg_out(j) = sum_i A_{ij}
  Constraints:
* deg_in(i) ≥ d_in_min for all i
* deg_out(i) ≥ d_out_min for all i
  Optionally:
* deg_in(i) ≤ d_in_max, deg_out(i) ≤ d_out_max for all i (controls fan-in/out and compute).

C3) Connectivity constraint (ensure information flow)
We require the directed graph to have a single large strongly connected component (SCC) covering at least a fraction ρ_scc of nodes:

* Let SCC_max(A) be size of largest SCC under adjacency A.
  Constraint:
* SCC_max(A) ≥ ρ_scc · H

C4) Bounded path-length proxy (avoid long chains)
Compute average shortest path length ℓ̄ on the giant SCC (or an undirected symmetrized version if needed):

* ℓ̄(A) = average_{(u,v) in SCC pairs} dist(u,v)
  Constraint:
* ℓ̄(A) ≤ ℓ_max
  (If dist undefined for directed pairs, use dist on undirected version A∨A^T.)

C5) Modularity/community constraint (NCP-like prior)
Partition nodes into M communities (M fixed, e.g., 3 or 4):

* community assignment c(i) ∈ {1..M}
  Define:
* intra-community edges: E_intra = {(j→i) ∈ E : c(i)=c(j)}
* inter-community edges: E_inter = E \ E_intra
  Constraint:
* |E_inter| / |E| ≤ r_inter_max
  This encourages modularity (interpretable + often stabilizing), while allowing limited cross-talk.

NOTE: C5 is a NEW mechanism only in the search constraint; it does not require modifying CfC equations.

3.3 Compute estimate used in search (NEW to objective)
Define a coarse compute score:

* Compute(A) = α_E · |E| + α_CP · CP(A)
  where CP(A) is a “critical path” proxy (e.g., longest shortest path length; or simply ℓ̄(A)).
  If CP is expensive, set Compute(A) = |E| only.

This compute estimate is used only for ranking candidates; final compute is measured empirically later.

3.4 Proxy metrics used in search (EXISTING functionality + expanded logging)
Let m(A) ∈ R^p be a vector of graph metrics already used / studied (examples; use the subset you already have robust code for):

* Topological entropy proxy TE(A)
* Curvature proxy ORC(A)
* Clustering coefficient C(A)
* Average path length ℓ̄(A)
* Degree variance Var(deg_in), Var(deg_out)
* Modularity Q(A) (if computed)
* Spectral radius proxy ρ(A) (optional, for stability heuristics)
  These are not “new mechanisms” unless newly introduced; the novelty is calibration + compute-aware constrained selection.

3.5 Search score (NEW objective; training-free)
We do NOT hand-tune weights. Instead we learn a calibrated predictor (Section 4).
During search, each candidate A is scored via predicted outcomes:

* \hat{y}_clean(A): predicted clean performance
* \hat{y}_rob(A): predicted robustness (e.g., predicted AUPC)
  Then define a Pareto ranking with compute penalty:
* Objective vector: [\hat{y}_rob(A), \hat{y}_clean(A), -Compute(A)]
  Selection rule: retain top K candidates on the estimated Pareto frontier (K small, e.g., 10–20).

4. PROXY CALIBRATION SPECIFICATION (MAJOR CHANGE 1: NEW calibration step)

---

4.1 Calibration dataset of graphs (NEW)
Sample N_cal candidate graphs {A_g}_{g=1..N_cal} from the constrained search space.

* N_cal target: 20–50 (fixed budget).
  Sampling must cover the feasible region (vary |E|, modularity, TE/ORC regimes).

4.2 Low-fidelity training protocol for calibration (NEW protocol, uses existing trainer)
Purpose: obtain approximate rankings cheaply.
Low-fidelity knobs (use at least 2 of these; exact choice depends on your harness):

* epochs: E_cal small (e.g., 3–5)
* seeds: S_cal = 1
* model width: H_cal < H_full (e.g., half)
* data subsample: subset of subjects/trials
* shorter sequences/bins: T_cal < T_full
  Record the low-fidelity outcomes:
* y_clean_cal(A_g): validation clean performance
* y_rob_cal(A_g): validation robustness proxy (choose one perturbation type or a very small set)

4.3 Calibrator model (NEW)
Fit a regression from proxy features to outcomes:
Let φ(A) be the feature vector used by the calibrator:

* φ(A) = [m(A), |E|, deg stats, modularity stats, ...]
  Train models:
* f_clean: φ(A) → y_clean_cal(A)
* f_rob:  φ(A) → y_rob_cal(A)
  Use a simple, fast method:
  Option 1: ridge regression (linear, stable)
  Option 2: gradient boosted trees (captures interactions)
  Option 3: GP regression (if you want uncertainty; optional)

Output:

* \hat{y}_clean(A) = f_clean(φ(A))
* \hat{y}_rob(A)   = f_rob(φ(A))

4.4 Calibrator evaluation (NEW)
Use k-fold CV over the N_cal graphs (k=5 if N_cal≥25) to assess:

* rank correlation (Spearman) between predicted and observed y’s
* calibration error (RMSE)
  The calibrator is accepted if rank correlation is meaningfully positive (threshold pre-specified, e.g., ρ_spearman ≥ 0.3). If not met, adjust constraints/features (do not expand training budget).

4.5 Search execution (NEW)
Run proxy search over N_search graphs (large; e.g., 10^4–10^5 feasible samples) using:

* constraints from Section 3
* scoring from \hat{y}_clean, \hat{y}_rob, Compute(A)
  Return shortlist:
* A_top = top K Pareto-optimal candidates (K=10, fixed)

5. STABILITY-AWARE CfC REGULARIZATION SPECIFICATION (MAJOR CHANGE 2)

---

5.1 Baseline training loss (EXISTING)
For supervised tasks with label y:

* Classification: L_task = CrossEntropy(ŷ, y)
* Regression: L_task = ||ŷ - y||^2
  Total baseline: L = L_task + (existing regularizers if any, e.g., weight decay).

5.2 NEW regularization: sensitivity (Jacobian) penalty
We define local hidden sensitivity:
(1)  J_t = ∂h_{t+1} / ∂h_t  ∈ R^{H×H}

We avoid computing full J_t. Use a stochastic directional estimate:

* Sample v ∼ N(0, I_H) (or Rademacher ±1).
  Compute:
  (2)  s_t(v) = || J_t v ||_2^2

Define the regularizer:
(3)  R_sens = E_{t,v} [ s_t(v) ]
Approximate by sampling one v per batch and averaging over time steps t included in BPTT window.

Implementation note:

* J_t v is computed via vector-Jacobian product (autodiff) without forming J_t.

Total loss becomes:
(4)  L_total = L_task + λ_sens · R_sens + λ_wd · ||θ||_2^2  (plus any existing terms)

NEW mechanism: R_sens and its computation.

5.3 NEW mechanism: Δt randomization
Instead of a fixed Δt, train with randomized Δt_t:
(5)  Δt_t ∼ Uniform(Δt0 · (1-δ), Δt0 · (1+δ))
where Δt0 is nominal step and δ ∈ (0,1) is a small band (e.g., δ=0.1–0.5 depending on how aggressive you want invariance).

This changes only the input to CfC update; does not change architecture.

5.4 NEW optional mechanism: Δt consistency penalty
To explicitly encourage smooth dependence on Δt:
Sample two increments Δt_a, Δt_b independently from the same band.
Compute:
(6)  h_{t+1}^{(a)} = U_θ(h_t, x_t, Δt_a)
(7)  h_{t+1}^{(b)} = U_θ(h_t, x_t, Δt_b)

Define:
(8)  R_Δt = E_{t} [ || h_{t+1}^{(a)} - h_{t+1}^{(b)} ||_2^2 ]

Add to loss:
(9)  L_total = L_task + λ_sens·R_sens + λ_Δt·R_Δt + λ_wd·||θ||_2^2

This is optional; if compute is too high, omit R_Δt and rely on Δt randomization alone.

5.5 NEW optional mechanism: Graph feasibility stability micro-test (filter, no training)
Before committing to training a candidate graph A:

* Initialize model weights with standard init.
* Run forward pass on synthetic input (Section 6) for T_micro steps.
* Compute:

  * max_t ||h_t||_2
  * max_t ||J_t v||_2 (directional)
  * gradient norm ||∂L_dummy/∂θ||_2 for a dummy scalar L_dummy = sum_t ||h_t||_2^2
    Reject A if any statistic exceeds a fixed threshold (pre-specified).
    This reduces wasted training runs on unstable graphs.
    This is NEW and does not require EEG.

6. TOY EXPERIMENTS (PRIMARY EVIDENCE FOR MAJOR CHANGE 2; EEG-FREE)

---

General principles:

* Toy experiments are used to validate dynamical claims: reduced sensitivity, bounded state norms, improved robustness to perturbations, improved invariance to Δt shifts.
* Use small H (e.g., 32–128) and small models; run many seeds cheaply.
* For each toy experiment, compare:
  (B0) baseline CfC (no new regularizers, fixed Δt)
  (B1) + Δt randomization only
  (B2) + R_sens only
  (B3) + Δt randomization + R_sens (primary recommended)
  (B4) + Δt randomization + R_sens + R_Δt (optional)

6.1 Toy Set 1: Unsupervised dynamical stability under perturbations (NO training required)
Purpose: measure the intrinsic stability of hidden state evolution under perturbations.

Inputs:
Choose one or more synthetic input processes x_t:

* White noise: x_t ~ N(0, I_D)
* Band-limited noise: filter white noise to low-pass or band-pass
* Burst process: x_t = 0 except occasional pulses
* Chirp: sinusoid with changing frequency (continuous-valued)

Procedure (per seed):

1. Initialize h_0 = 0 (or fixed random vector).
2. Generate x_{0..T-1} for T steps.
3. Run baseline and regularized models forward WITHOUT training (weights at init).
4. Create perturbed trajectories:
   (A) hidden perturbation: h'_0 = h_0 + ε, ε~N(0, σ_h^2 I)
   (B) input perturbation: x'_t = x_t + η_t, η_t~N(0, σ_x^2 I)
5. Compute divergence:
   (10) D_h(T) = || h_T - h'_T ||_2
   (11) D_h(t) = || h_t - h'_t ||_2 for t=1..T (curve)
   Similarly for input-perturbed.

Metrics:

* Divergence curve slope: fit log D_h(t) vs t to estimate effective growth rate.
* Max hidden norm: max_t ||h_t||_2
* Directional sensitivity: average_t ||J_t v||_2^2 with v sampled once per run.
* Failure rate: fraction of runs with NaN/Inf or exploding norms.

Expected outcomes:

* Regularized variants should show smaller divergence growth and smaller sensitivity proxy.

NOTE: This toy does not require any learning; it supports claims about the *inductive bias / stability* of the update map under the added regularization terms when applied during training (we will also train in Toy Set 2).

6.2 Toy Set 2: Supervised “noisy delayed copy” (minimal diagnostic task)
Purpose: measure robust memory and sensitivity to input noise in a controlled way.

Task definition:
Let u_t ∈ R be a random scalar sequence (or one-hot symbols).
Define input x_t = u_t + η_t (η_t noise).
Target is to predict u_{t-k} after delay k (fixed).
Formally:
(12) y_t = u_{t-k}
Model output:
(13) ŷ_t = R_ψ(h_t)
Loss:
(14) L_task = E_t [ (ŷ_t - y_t)^2 ]  (MSE)

Training setup:

* Train for small epochs E_toy (e.g., 10–30) on short sequences.
* Train under a nominal noise σ_train.
  Evaluate robustness by testing at higher σ_test levels.

Robustness metrics:

* Error vs noise: MSE(σ_test)
* Sensitivity proxy during inference: average ||J_t v||^2
* Δt shift robustness: train with Δt band, test on shifted band.

Hypothesis:

* R_sens + Δt randomization yields flatter error vs noise curve (better robustness).

6.3 Toy Set 3: Δt shift test (explicitly targets CfC time dependence)
Purpose: prove Δt regularization gives invariance to discretization.

Procedure:

* Train on Δt ∼ Uniform(Δt0(1-δ), Δt0(1+δ)).
* Test on:
  (i) fixed Δt = Δt0
  (ii) shifted Δt = Δt0(1+δ_shift), where δ_shift > δ (out-of-band)
  Compare baseline vs regularized variants.

Outcome metrics:

* Performance drop under Δt shift
* Hidden sensitivity proxy under shift
* Divergence/instability frequency under shift

6.4 Reporting for toy experiments
For each toy experiment:

* Run S_toy seeds (e.g., 10–20).
  Report:
* median, IQR for each metric
* divergence curves with confidence bands
* sensitivity distributions

These results are intended for main-paper mechanistic validation or appendix, and do not require EEG compute.

7. MINIMAL EEG CONFIRMATION EXPERIMENTS (LINK MECHANISM TO APPLICATION)

---

Principles:

* Do not ablate across many datasets for mechanism validation.
* Use EEG only to confirm that mechanisms translate to decoding robustness.
* Use the smallest number of full training runs consistent with credible evidence.

7.1 EEG dataset choice (EXISTING)
Select exactly one dataset/split that is already in your pipeline and representative:

* Prefer BNCI2014_001 (MI) cross-session (if it is your main benchmark in Paper 2/1).
  Keep all preprocessing and evaluation identical to existing pipelines.

7.2 Models evaluated (minimal set)
Pick:

* Graphs:
  (G0) baseline graph (current Paper 3 baseline wiring)
  (G1) top-1 graph from proxy-calibrated Pareto shortlist
  (G2) top-2 graph from proxy-calibrated Pareto shortlist (optional if budget allows)

* Regularization:
  (R0) baseline training (no new stability regularizers; fixed Δt)
  (R1) stability-aware (Δt randomization + R_sens; R_Δt optional if it clearly helped in toys)

Total training runs:

* 1 graph (baseline) × 2 regs + 1 graph (best) × 2 regs = 4 full runs
  Optionally add second best graph: +2 runs.
  Seeds:
* S_eeg = 1–2 seeds max. Prefer 2 if feasible.

7.3 EEG robustness evaluation (EXISTING metrics)
Use the robustness metrics from Paper 1:

* Clean ROC-AUC on unperturbed test
* AUPC under:

  * Gaussian noise
  * EOG artifacts
  * Channel dropout
    (choose 1–2 perturbations if compute is too high; pre-specify priority order)

Also record:

* Training stability: divergence/NaNs
* Inference time per trial (measured)
* Sensitivity proxy on EEG minibatches at inference: average ||J_t v||^2 (optional but helpful)

Success criteria (pre-specified):

* Stability-aware training should improve robustness metric(s) without material clean performance loss beyond a small tolerance.
* Best calibrated graph should be competitive or better at equal compute.

7.4 Result presentation

* Main: Pareto plot (predicted vs realized) for shortlisted graphs.
* Main: EEG confirmation table for baseline vs best graph, with and without stability regularization.
* Appendix: toy dynamics figures (divergence curves, sensitivity).

8. STRETCH GOAL: TWO-TIMESCALE RECURRENCE (OPTIONAL)

---

Only executed if compute remains after Sections 6–7.

8.1 Architecture (NEW)
Maintain fast state h^f_t ∈ R^{Hf} and slow state h^s_t ∈ R^{Hs}.
Fast update every step:
(15) h^f_{t+1} = U^f(h^f_t, [x_t; h^s_t], Δt_t)
Slow update every M steps:
Define pooled input over a window:
(16) \bar{x}*{t} = Pool(x*{t-M+1..t})  (e.g., mean or learned pooling)
Then:
(17) h^s_{t+1} = h^s_t   if (t+1) mod M ≠ 0
(18) h^s_{t+1} = U^s(h^s_t, \bar{x}_{t}, Δt^s_t)  if (t+1) mod M = 0
Output can depend on h^f_t or concatenation [h^f_t; h^s_t].

8.2 Evidence (toy-first)
Run Toy Set 2 and Toy Set 3 with two-timescale vs baseline CfC under equal compute budget.
EEG confirmation only if toy results are clearly positive.

This stretch is not required for primary claims.

* Clearly label each component as:
  NEW MECHANISM: calibration predictor; constrained compute-aware search; sensitivity regularizer; Δt randomization/consistency; feasibility micro-test; two-timescale recurrence.

  EXISTING FUNCTIONALITY: CfC cell implementation; robustness metrics computation (AUPC/RD); EEG pipeline preprocessing and splits; existing proxy computations (TE/ORC etc.) if already implemented.

10. MINIMAL RUN BUDGET SUMMARY (TARGET)

---

Toy experiments:

* 3 toy suites × 4 variants (B0–B3) × 10–20 seeds = cheap CPU/GPU minutes-hours.

Topology calibration:

* N_cal = 20–50 graphs × low-fidelity training (3–5 epochs, 1 seed) = moderate but bounded.
