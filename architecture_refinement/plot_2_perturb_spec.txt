====================================================================
Plot 2 – Correlated Perturbation Specification
====================================================================

Purpose
-------
This document specifies three correlated perturbation models for
evaluating topology-dependent robustness in MI EEG decoding.
These perturbations are designed to stress recurrent dynamics and
spatiotemporal integration mechanisms that are not sufficiently
challenged by i.i.d. Gaussian noise.

All perturbations integrate directly with the existing Plot 2 pipeline:
- Cross-session evaluation (BNCI2014_001)
- Fixed-capacity CNN–CfC / CNN–NCP models
- 5-point perturbation grid
- AUPC robustness metric
- Shared SNR-based intensity calibration

--------------------------------------------------------------------
Common Framework (Applies to All Perturbations)
--------------------------------------------------------------------

Let X ∈ ℝ^{T × C} denote a single EEG trial (time × channels).

Perturbed signal:
    X̃ = X + α · ε

Perturbation intensity α is scaled relative to a fixed maximum α_max
defined via a target signal-to-noise ratio (SNR):

    SNR_dB = 10 log10( E[||X||_F^2] / E[||α_max ε||_F^2] )

Unless otherwise stated, α_max is chosen such that:
    SNR_dB ≈ 0 dB

The perturbation grid is:
    α ∈ {0, 0.25, 0.5, 0.75, 1.0} · α_max

This matches the existing Plot 2 AUPC computation exactly.

--------------------------------------------------------------------
Perturbation 1 (Primary): Spatially Correlated Gaussian Noise
--------------------------------------------------------------------

Definition
----------
Noise ε is sampled from a zero-mean multivariate Gaussian with spatial
covariance Σ_s across channels:

    ε ~ 𝒩(0, Σ_s)

The spatial covariance is defined by electrode distances:

    (Σ_s)_{ij} = exp( − d_{ij} / ℓ )

where:
- d_{ij} is the Euclidean distance between electrodes i and j,
- ℓ > 0 is a spatial correlation length.

Implementation
--------------
- Use known EEG montage coordinates (10–20 system).
- Compute d_{ij} once per dataset.
- Precompute Cholesky factor L such that Σ_s = L Lᵀ.
- Sample ε = Z Lᵀ, where Z ~ 𝒩(0, I).

Default Parameters
------------------
- Correlation kernel: exponential
- ℓ: median inter-electrode distance
- α_max: calibrated to SNR ≈ 0 dB

Justification
-------------
This perturbation models:
- motion-induced electrode coupling,
- cable sway and reference contamination,
- volume conduction–like correlated interference.

Spatially coherent noise is known to degrade CNN spatial filters more
strongly than i.i.d. noise and forces downstream recurrence to
compensate.

Integration with Plot 2
-----------------------
- Drop-in replacement for existing Gaussian noise generator.
- Uses the same α grid and AUPC computation.
- No change to training or evaluation code paths.

--------------------------------------------------------------------
Perturbation 2 (Secondary): Temporally Correlated Drift (AR(1))
--------------------------------------------------------------------

Definition
----------
Noise is generated via an autoregressive process:

    ε_t = ρ ε_{t−1} + η_t ,   η_t ~ 𝒩(0, σ²)

This is applied independently per channel or as a shared latent
component projected to channels.

Perturbed signal:
    X̃ = X + α · ε

Default Parameters
------------------
- ρ = 0.97 (strong temporal correlation)
- σ² chosen such that ε has unit variance before scaling
- α_max calibrated to SNR ≈ 0 dB

Justification
-------------
AR(1) noise approximates:
- slow baseline drift,
- motion-induced nonstationarity,
- low-frequency physiological artifacts.

These perturbations directly challenge temporal stability and
long-range integration, which are central to recurrent topology.

Integration with Plot 2
-----------------------
- Uses the same α grid and AUPC metric.
- Implemented as a new noise generator class.
- No changes to evaluation logic.

--------------------------------------------------------------------
Perturbation 3 (Exploratory / Appendix): Band-Limited EMG-Like Noise
--------------------------------------------------------------------

Definition
----------
Noise is generated by band-limiting white noise to high frequencies:

    ε = BP_{[f_l, f_h]}( η ),   η ~ 𝒩(0, I)

Optionally modulated by a slowly varying envelope a(t):

    ε(t) = a(t) · BP_{[f_l, f_h]}(η(t))

Perturbed signal:
    X̃ = X + α · ε

Default Parameters
------------------
- Band: f_l = 20 Hz, f_h = 80 Hz
- Envelope a(t): low-frequency Gaussian-smoothed noise (optional)
- α_max calibrated to SNR ≈ 0 dB

Justification
-------------
EMG contamination is a well-documented failure mode for SMR MI systems.
High-frequency noise leaks into band-power estimates and interacts
poorly with normalization and temporal aggregation.

Integration with Plot 2
-----------------------
- Same α grid and AUPC computation.
- Intended primarily for appendix or robustness breadth analysis.

--------------------------------------------------------------------
Expected Behavior and Validation
--------------------------------------------------------------------

For each perturbation, the following must hold at α = α_max:
- Mean ROC-AUC drops by ≥ 0.05 relative to clean for at least one model.
- AUPC < 1.0 with visible degradation across α.
- Variance across architectures exceeds variance across seeds.

If these conditions are not met:
- Reduce target SNR (e.g., −5 dB), or
- Increase spatial correlation length ℓ (Perturbation 1), or
- Increase temporal correlation ρ (Perturbation 2).

--------------------------------------------------------------------
Notes on Scientific Interpretation
--------------------------------------------------------------------

- Perturbation 1 serves as the **primary Plot 2 stress test**.
- Perturbation 2 tests sensitivity to nonstationarity and recurrence.
- Perturbation 3 demonstrates relevance to known physiological artifacts.

Gaussian i.i.d. noise is retained as a negative control, confirming that
simple additive noise is insufficient to expose topology-dependent
robustness in CNN-based MI decoding.

--------------------------------------------------------------------
End of Specification 1

Plot 2 – Correlated Perturbation Execution Specification
====================================================================

Purpose: Specification 2
-------
This document specifies the immediate next steps following the
one-model perturbation pilot. It formalizes which perturbations are
promoted to full Plot 2 evaluation, which require escalation, and how
those escalations are to be validated before inclusion.

This specification ensures that full Plot 2 runs are only conducted
with perturbations that demonstrably stress MI decoding models.

--------------------------------------------------------------------
Summary of Pilot Outcomes
--------------------------------------------------------------------

Pilot evaluation at SNR_max ≈ 0 dB yielded:

- AR(1) temporally correlated drift:
    ΔROC-AUC ≥ 0.05, monotonic degradation, PASSED

- Spatially correlated Gaussian noise:
    ΔROC-AUC < 0.05, non-monotonic at low intensity, FAILED

- EMG band-limited noise:
    ΔROC-AUC < 0.05, monotonic but weak degradation, FAILED

These outcomes indicate that only AR(1) drift is sufficiently
destructive at default severity.

--------------------------------------------------------------------
Promotion to Full Plot 2 Evaluation
--------------------------------------------------------------------

Primary Plot 2 perturbation:
- AR(1) temporally correlated drift

This perturbation is promoted immediately to full multi-model Plot 2
evaluation without modification.

Default parameters (unchanged from pilot):
- AR coefficient: ρ = 0.97
- SNR_max ≈ 0 dB
- Intensity grid:
    α ∈ {0, 0.25, 0.5, 0.75, 1.0} · α_max

This perturbation becomes the **main robustness stress test** reported
in the primary Plot 2 figure.

--------------------------------------------------------------------
Escalation Plan for Secondary Perturbations
--------------------------------------------------------------------

The following perturbations are retained but require severity
escalation and re-validation via the one-model pilot protocol before
being included in full Plot 2 runs.

--------------------------------------------------------------------
Secondary Perturbation A: Spatially Correlated Gaussian Noise
--------------------------------------------------------------------

Current status:
- Insufficient degradation at SNR_max ≈ 0 dB

Escalation procedure (apply in order):

Step 1: Increase severity via SNR
- Recompute α_max targeting:
      SNR_max ≈ −5 dB
- Keep spatial kernel and ℓ unchanged

Re-run one-model perturbation pilot.

If still insufficient:

Step 2: Increase spatial coherence
- Double correlation length:
      ℓ ← 2 · ℓ
- Keep SNR_max at −5 dB

Re-run one-model perturbation pilot.

Promotion criterion:
- ΔROC-AUC ≥ 0.05 at α = α_max
- Clear monotonic or near-monotonic degradation trend

--------------------------------------------------------------------
Secondary Perturbation B: EMG Band-Limited Noise
--------------------------------------------------------------------

Current status:
- Monotonic but weak degradation at SNR_max ≈ 0 dB

Escalation procedure (apply in order):

Step 1: Increase severity via SNR
- Recompute α_max targeting:
      SNR_max ≈ −5 dB
- Keep band limits unchanged

Re-run one-model perturbation pilot.

If still insufficient:

Step 2: Increase physiological realism
- Enable slow amplitude envelope (bursty EMG), OR
- Widen band to 20–100 Hz

Re-run one-model perturbation pilot.

Promotion criterion:
- ΔROC-AUC ≥ 0.05 at α = α_max
- Monotonic degradation preferred

--------------------------------------------------------------------
One-Model Pilot Reuse
--------------------------------------------------------------------

All escalation checks must use the same:
- Dataset (BNCI2014_001)
- Cross-session split
- Fixed trained model checkpoint
- Fixed training seed
- Evaluation code path

No retraining or NAS selection is permitted during escalation checks.

--------------------------------------------------------------------
Integration with Plot 2 Infrastructure
--------------------------------------------------------------------

- AR(1) drift is integrated immediately into the full Plot 2 runner.
- Escalated perturbations must pass the one-model pilot before:
    - being added to the Plot 2 configuration,
    - being included in any multi-model evaluation,
    - or contributing to AUPC comparisons.

Gaussian i.i.d. noise remains as a documented negative control and is
not used for topology-sensitive evaluation.

--------------------------------------------------------------------
Expected Outcomes
--------------------------------------------------------------------

Following this specification:
- Plot 2 is guaranteed to include at least one perturbation that
  meaningfully stresses temporal dynamics.
- Additional perturbations may be added without risking null results.
- Full Plot 2 compute is protected from weak or non-discriminative
  perturbations.

--------------------------------------------------------------------
End of Specification 2

Plot 2 – Post-Pilot Execution Plan and Required Patches (Spec)
====================================================================

Purpose
-------
This specification consolidates the finalized next steps following the
escalated one-model pilot reruns (target SNR = −5 dB) and enumerates
the required patches to existing infrastructure before launching the
full Plot 2 evaluation.

Outcome: proceed to full Plot 2 using correlated perturbations that are
confirmed to stress MI decoding models, while fixing the remaining
reporting/telemetry issues that could invalidate interpretation.

--------------------------------------------------------------------
Pilot Status Summary (Decision Gate)
--------------------------------------------------------------------

The escalated pilot reruns confirm that the following perturbations now
induce sufficient degradation at maximum intensity:

- AR(1) temporally correlated drift: PASSED (strong monotone drop)
- Spatially correlated Gaussian: PASSED (clear degradation)
- EMG band-limited noise: PASSED (monotone degradation)

Therefore:
- Plot 2 must pivot away from i.i.d. Gaussian as the primary stress test.
- Correlated perturbations are promoted for full multi-model evaluation.

--------------------------------------------------------------------
Final Perturbation Set for Full Plot 2
--------------------------------------------------------------------

Primary stress test (main Plot 2 result):
1) AR(1) temporally correlated drift
   - Default: ρ = 0.97
   - Max intensity calibrated by target SNR (use −5 dB for Plot 2)

Secondary stress tests (main or appendix depending on page budget):
2) Spatially correlated Gaussian noise
   - Σ_ij = exp(−d_ij / ℓ)
   - Default: ℓ = median inter-electrode distance
   - Max intensity: target SNR = −5 dB

3) EMG band-limited noise
   - Default band: 20–80 Hz
   - Step-2 realism option (if enabled): amplitude envelope (bursty EMG)
   - Max intensity: target SNR = −5 dB

Negative control (appendix or brief mention):
- i.i.d. Gaussian noise (original Plot 2 attempt)
  - Retain as a null condition demonstrating that simple additive noise
    does not expose topology-dependent robustness in this pipeline.

--------------------------------------------------------------------
Required Patches (Must Implement Before Full Plot 2)
--------------------------------------------------------------------

PATCH 1: Correct SNR Reporting in Pilot and Plot 2 Logs
------------------------------------------------------
Observed issue:
- Escalated pilot results show stronger degradation consistent with
  increased noise power, but summary outputs still report "SNR_max = 0 dB"
  (likely stale logging or incorrect variable passed to reporter).

Requirements:
- Log BOTH:
  (a) target SNR used to compute α_max (e.g., −5 dB), AND
  (b) empirical achieved SNR on the evaluated set (computed from actual
      ||X||_F^2 and ||α_max ε||_F^2 using the same formula).

- Store these values in:
  - per-perturbation summary (CSV/JSON)
  - run-level report.txt
  - figure caption metadata (optional but recommended)

Acceptance test:
- For a run configured with target SNR = −5 dB, the report must show:
  - target_snr_db = −5.0
  - empirical_snr_db close to −5.0 (within tolerance)

PATCH 2: Ensure α_max Calibration Uses the Correct Reference Energy
-------------------------------------------------------------------
Risk:
- If α_max is computed using a different data slice than evaluation
  (train vs test, per-trial vs dataset mean), the realized SNR may drift.

Requirements:
- Define a single canonical calibration procedure:
  - Compute E[||X||_F^2] over the evaluation split to be perturbed
    (cross-session test set for Plot 2).
  - Compute E[||ε||_F^2] under unit-scale noise generation for the same
    split (or analytically if stable).
  - Solve for α_max to achieve target SNR.

- Cache α_max per perturbation type and dataset split with a hash of:
  (dataset, split, perturbation_type, key parameters such as ρ, ℓ, band)

Acceptance test:
- Re-running calibration with fixed RNG seeds yields identical α_max.

PATCH 3: Configuration Plumbing for Perturbation Type and Parameters
-------------------------------------------------------------------
Requirements:
- Add a single switch to the Plot 2 runner config:
    perturbation_type ∈ {ar1_drift, spatial_gaussian, emg_band, iid_gaussian}
- Add a structured block per perturbation:
  - ar1_drift: rho
  - spatial_gaussian: ell, kernel type (fixed: exp)
  - emg_band: f_low, f_high, envelope_on (bool), envelope_params (if used)
- Add:
    target_snr_db (default for Plot 2: −5.0)

Acceptance test:
- A single runner invocation can iterate over perturbation types without
  modifying code.

Note (Plot 2 bug fix): Report and plot must reflect the actual applied
perturbation. The analyzer validates that the primary_perturbation_type
in the manifest matches the noise_type present in the result CSVs; if
only gaussian is present but manifest says ar1_drift, it warns and
reports using gaussian. All outputs record perturbation_type,
target_snr_db, and empirical_snr_db. Runtime assertions ensure ar1_drift
uses the correlated path (alpha_max) and not gaussian sigma_max.

PATCH 4: Reproducibility and Artifact Isolation
-----------------------------------------------
Requirements:
- All outputs for Plot 2 correlated perturbations must be stored under
  dedicated run IDs and directories, distinct from:
  - NAS Pilot / Plot 1 outputs
  - training-free Optuna study logs
  - previous i.i.d. Gaussian Plot 2 artifacts

- Persist a "run manifest" containing:
  - git commit hash (or code version id)
  - dataset + evaluation protocol
  - model_id and checkpoint id
  - perturbation type + parameters
  - target and empirical SNR
  - RNG seeds used for perturbation generation

Acceptance test:
- No file paths are shared across perturbation runs unless explicitly
  intended (e.g., same checkpoint reused).
