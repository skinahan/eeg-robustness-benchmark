ISSUE 4: Broken Confidence Intervals (CI Artifacts)
================================================================================

PROBLEM:
--------
Several CIs are obviously broken with extreme values:
- [-1747.52, -0.69] (BNCI2014_001 Cross-subject, line 108)
- [-733.26, -1.85] (BI2015a Cross-subject, line 81)
- [7.44, 169.41] (BI2015a Cross-subject AUPC tuned, line 386)
- [-0.27, 68.95] (Lee2019_SSVEP Cross-subject AUPC untuned, line 354)

ROOT CAUSE ANALYSIS:
-------------------
The bootstrap CI function (statistical_analysis.py, lines 818-850) appears 
correct, but extreme values suggest:

1. VERY SMALL SAMPLE SIZES:
   - Cross-subject evaluations typically have n=3 (one per subject)
   - Bootstrap with n=3 is extremely unstable
   - Single extreme bootstrap sample can dominate percentiles

2. EXTREME EFFECT SIZES:
   - When std_diff is very small (near-zero variance in differences), 
     Cohen's dz can be extremely large
   - Bootstrap resampling can amplify this

3. BOOTSTRAP INSTABILITY:
   - With n=3, bootstrap has only 3^3 = 27 possible unique resamples
   - Percentile calculation on such small distribution is unreliable

EXAMPLE ANALYSIS:
-----------------
For BI2015a Cross-subject (likely n=3):
- HYDRA vs CNN-NCP: dz = -2.92, CI = [-189.43, -2.33]
- The CI lower bound is 65x larger than the point estimate
- This suggests bootstrap found one extreme resample where std_diff was 
  extremely small, making dz explode

TECHNICAL ISSUE:
----------------
In bootstrap_ci_cohens_dz():
- No check for minimum sample size
- No outlier detection in bootstrap distribution
- No clipping of extreme percentiles
- No fallback to analytical CI when n is too small

RECOMMENDED FIXES:
------------------
1. Add minimum sample size check:
   ```python
   if n < 5:  # Too small for reliable bootstrap
       # Use analytical CI or return wider bounds
       return (np.nan, np.nan)  # Or use t-distribution CI
   ```

2. Use analytical CI for small samples:
   ```python
   if n < 10:
       # Use t-distribution based CI for Cohen's dz
       # dz ~ t-distribution with n-1 df
       from scipy.stats import t
       t_crit = t.ppf(0.975, n-1)
       se_dz = 1 / np.sqrt(n)  # Approximate SE
       ci_low = cohens_dz - t_crit * se_dz
       ci_high = cohens_dz + t_crit * se_dz
       return (ci_low, ci_high)
   ```

3. Add outlier detection in bootstrap:
   ```python
   # Remove extreme outliers (beyond 3 SD from median)
   median_dz = np.median(dz_bootstrap)
   mad = np.median(np.abs(dz_bootstrap - median_dz))
   if mad > 0:
       z_scores = np.abs((dz_bootstrap - median_dz) / (1.4826 * mad))
       dz_bootstrap = dz_bootstrap[z_scores < 3]
   ```

4. Clip percentiles to reasonable bounds:
   ```python
   ci_low = np.percentile(dz_bootstrap, 100 * alpha / 2)
   ci_high = np.percentile(dz_bootstrap, 100 * (1 - alpha / 2))
   
   # Clip to reasonable bounds (e.g., ±10x point estimate)
   point_estimate = compute_cohens_dz(x, y)
   if np.isfinite(point_estimate):
       max_bound = 10 * abs(point_estimate)
       ci_low = max(ci_low, -max_bound)
       ci_high = min(ci_high, max_bound)
   ```

5. Add warning/flag for unreliable CIs:
   ```python
   if n < 5:
       return (ci_low, ci_high, True)  # Flag as unreliable
   ```

IMPACT:
-------
- Current broken CIs make results look unreliable
- Reviewers will question statistical rigor
- May need to exclude or flag cross-subject results with n < 5
- Consider reporting only point estimates for very small samples
